## Questions courantes

**Dois-je changer mes outils ?**
Non. L'automatisation se branche sur ceux que vous utilisez déjà, via Microsoft Graph, OAuth 2.0 ou des API REST.

**Mes accès sont-ils protégés ?**
Oui. Je me connecte par OAuth 2.0 : vous n'avez jamais à me communiquer un mot de passe.

**Pourquoi du code plutôt que du no-code ?**
Le code est écrit à la main, en Python et en TypeScript. Le comportement de l'agent est donc défini ligne par ligne, et je peux l'ajuster à votre activité plutôt que de me limiter aux blocs d'un outil.
